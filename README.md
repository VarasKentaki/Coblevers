# 🎮 Cobblemon Drops Dex

Una Pokédex de drops para Cobblemon desarrollada por fans.

Permite buscar Pokémon, consultar sus drops, filtrar por generación, ordenar resultados y guardar favoritos localmente.

## Características

- 🔍 Búsqueda instantánea
- ⭐ Sistema de favoritos
- 🎲 Consulta de drops
- 📖 Información especial de biomas
- 🌎 Interfaz en español
- 📱 Diseño responsive
- ⬆ Botón para volver arriba
- 🔗 Enlaces directos a recursos externos

## Tecnologías

- HTML5
- CSS3
- JavaScript Vanilla
- LocalStorage
- JSON

## Fuentes utilizadas

- PokeAPI
- Cobblemon
- Cobblemon Tools
